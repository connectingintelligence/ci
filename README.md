# Connecting Intelligence website (v5)

Plain static site: index.html (Home), work.html (The work), people.html, privacy.html, plus assets/.
Exported from the Claude Design canvas on 17 October 2026.
No cookies, no analytics, no third-party requests: fonts are self-hosted in assets/fonts.

To preview locally: open index.html in a browser, or run `python3 -m http.server` in this folder.

To publish on GitHub Pages: put these files in the root of a GitHub repository,
then Settings > Pages > Deploy from branch (main, / root). The CNAME file already contains www.connectingintelligence.com (same as the live repo connectingintelligence/ci), so GitHub Pages picks up the custom domain.
Then tick "Enforce HTTPS" in Settings > Pages.
